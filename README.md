# 🚀 Portfólio Profissional - Guilherme Campagnolo

Bem-vindo ao meu portfólio profissional! Este é um site moderno, responsivo e otimizado que apresenta meus projetos, habilidades e experiências como desenvolvedor full stack.

## ✨ Características

- ✅ **Design Moderno e Profissional** - Estilo contemporâneo com gradientes e animações suaves
- ✅ **100% Responsivo** - Funciona perfeitamente em desktop, tablet e mobile
- ✅ **Performance Otimizada** - Carregamento rápido e eficiente
- ✅ **SEO Friendly** - Meta tags e estrutura semântica
- ✅ **Acessibilidade** - Navegação clara e intuitiva
- ✅ **Sem Dependências Externas** - HTML, CSS e JavaScript puro

## 🏗️ Estrutura do Projeto

```
portfolio/
├── index.html          # Arquivo principal HTML
├── styles/
│   ├── main.css        # Estilos principais
│   └── responsive.css  # Media queries responsivas
├── js/
│   └── main.js         # JavaScript funcional
├── .gitignore
├── package.json
└── README.md
```

## 🎯 Seções

1. **Navegação** - Menu sticky com links suaves
2. **Hero Section** - Apresentação com call-to-action
3. **Sobre** - Informações pessoais e estatísticas
4. **Habilidades** - Cards com tecnologias e ferramentas
5. **Projetos** - Portfólio com projetos destacados
6. **Contato** - Formulário de contato funcional
7. **Footer** - Rodapé com direitos autorais

## 🛠️ Como Usar

### Localmente

```bash
# Clone o repositório
git clone https://github.com/guilhermebcampagnolo/portfolio.git
cd portfolio

# Abra em um servidor local (Python)
python -m http.server 8000

# Ou abra diretamente no navegador
open index.html
```

### Deploy

Você pode fazer deploy em:
- **GitHub Pages** - Grátis e integrado com GitHub
- **Vercel** - Apenas conecte seu repositório
- **Netlify** - Drop and deploy
- **Heroku** - Cloud hosting

## 📱 Responsividade

- **Desktop** (1200px+) - Layout completo
- **Tablet** (768px - 1199px) - Adaptado
- **Mobile** (até 767px) - Menu hambúrguer e stack vertical

## 🎨 Personalização

Edite as cores no arquivo `styles/main.css`:

```css
:root {
    --primary-color: #6366f1;    /* Azul primário */
    --secondary-color: #ec4899;  /* Rosa secundária */
    --dark-color: #1f2937;       /* Escuro */
    --light-color: #f9fafb;      /* Claro */
}
```
